# Code of Conduct / 行为准则

We are committed to a welcoming, harassment-free community. Be respectful, assume good intent, focus criticism on ideas and code, and protect users' privacy. Harassment, discrimination, threats, doxxing, or publishing another person's private data are not acceptable.

我们致力于建立友善、无骚扰的社区。请保持尊重、善意理解他人，将批评聚焦于观点和代码，并保护用户隐私。骚扰、歧视、威胁、人肉搜索或公开他人隐私信息均不可接受。

Repository maintainers may edit, remove, or reject contributions and participation that violate these expectations. Report incidents privately to the repository owner.

仓库维护者可以编辑、删除或拒绝违反上述要求的内容和参与行为。相关事件请私下报告给仓库所有者。
